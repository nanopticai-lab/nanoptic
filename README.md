# Nanoptic Research

A one-person research lab studying how AI can build an internal model of the physical world (world models), with far less energy, taking ideas from how the brain works.

Pronounced *na-NOP-tic*. Director: Esethu (Seth) Tshintsholo.

- **Pico** is the lab's base model: a small world model built and trained from scratch.
- How the lab works: [`Nanoptic_Lab_Foundations_v1.1.pdf`](Nanoptic_Lab_Foundations_v1.1.pdf)
- Every study follows the lab protocol: question → survey → frozen plan → run → analyse → verify → self-review → publish → archive.
- AI use: code is written by Claude Code from plain-English workorders and checked with tests and independent second routes. Every write-up states how.
